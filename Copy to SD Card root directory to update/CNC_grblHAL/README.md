# CNC-иконки для grblHAL (TFT35)

В режиме grblHAL CNC-экраны (`TFT/src/User/Menu/Cnc.c`) показывают иконки из слотов принтерных иконок, которые в этом режиме не используются. Своих слотов для них нет, потому что внешняя флеш-память экрана заполнена. Какая иконка в каком слоте — см. алиасы в `TFT/src/User/Menu/Cnc.h`.

Как подготовить SD-карту:
1. Скопировать в корень карты `.bin` прошивки (`BIGTREE_TFT35_V3_0` или `BIGTREE_GD_TFT35_V3_0`).
2. Скопировать туда же папку `TFT35` из `THEME_Unified Menu Material theme`.
3. Поверх неё скопировать `TFT35/bmp` из этой папки, заменяя файлы.
4. Скопировать `TFT/src/User/config_grbl.ini` в корень карты под именем `config.ini`.

Иконки генерирует `test/grbl/make_cnc_icons.py`.
